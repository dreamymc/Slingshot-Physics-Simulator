Slingshot — modular pygame demo.

Run:
1. pip install -r requirements.txt
2. python -m slingshot

Features:
- Pan (LMB drag on empty space)
- Pull & shoot (LMB near anchor)
- Zoom (mouse wheel, centered on mouse)
- Landings saved in world coordinates (markers don't shift)
- Fixed ground line (world y=0 is locked)
- Last-pull box pinned to left (editable)
